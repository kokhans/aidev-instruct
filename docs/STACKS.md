# Stacks

Generated by `bun run docs` from `stacks/`. Do not edit by hand.

A stack is a named set of packs. A project can use several stacks, give each one a folder, and add single packs next to them.

```json
{
  "targets": ["copilot", "claude", "cursor"],
  "stacks": [
    { "name": "react-router-spa", "path": "apps/web" },
    { "name": "elysia-api", "path": "apps/api" },
    "public-site"
  ],
  "packs": ["docker"]
}
```

- A stack with a `path` applies only to that folder: rule globs are prefixed with it.
- `public-site` is an add-on for public sites. Combine it with a framework stack.
- Commands: `stacks`, `stacks add <stack...> [--path <folder>]`, `stacks remove <stack...>`, `init -s <list>`.
